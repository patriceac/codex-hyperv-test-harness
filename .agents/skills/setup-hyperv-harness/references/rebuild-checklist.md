# Rebuild checklist

1. Confirm Windows 11 Pro, Enterprise, or Education, firmware virtualization, signed Microsoft Edge, official-page reachability, BITS, IMAPI, the inbox C# compiler, at least 200 GiB free, and enough host memory.
2. Run the public repository audit and plan-only install.
3. Record install root, target user profile/SID, pool size, VM memory, display size, idle timeout, and language.
4. Start one installer. If Hyper-V enablement requires restart, verify the resume task and monitor the same attempt ID.
5. Require official-media validation: HTTPS Microsoft host, valid Microsoft signature, one Professional image, SHA-256 recorded.
6. Require the unattended guest agent to become ready on an interactive session and the clean checkpoint to exist.
7. Require the configured one-to-four pool definitions, immutable base, differencing children, disconnected worker network, SYSTEM broker task, and location pointer.
8. Require installed runtime skill and managed policy block without replacing unrelated Codex instructions.
9. Run the visual canary through the broker, never on the host.
10. Require payload child deletion, pool audit success, terminal setup success, and current local recovery manifest unless explicitly skipped.
11. Remind the user that Windows activation and licensing were not performed.
