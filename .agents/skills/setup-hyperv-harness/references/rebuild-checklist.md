# Rebuild checklist

1. Explain the complete rebuild and its host, storage, network, credential, reboot, licensing, recovery, verification, and destructive implications before making local changes.
2. Ask the user to select the exact non-root install directory, target account, pool size, VM memory/processors, display size, idle timeout, language, restart behavior, recovery-bundle behavior, and preservation requirements. Do not assume a drive or accept the answers as execution approval.
3. Present the exact proposed configuration and wait for explicit approval.
4. After approval, confirm Windows 11 Pro, Enterprise, or Education, firmware virtualization, signed Microsoft Edge, official-page reachability, BITS, IMAPI, the inbox C# compiler, at least 200 GiB free, and enough host memory.
5. Run the public repository audit and plan-only install with every selected value explicit. Show the plan and obtain a second approval before mutation.
6. Record install root, target user profile/SID, pool size, VM memory/processors, display size, idle timeout, language, restart choice, and recovery choice.
7. Start one installer with the unchanged approved values. If Hyper-V enablement requires restart, verify the resume task and monitor the same attempt ID.
8. Require official-media validation: HTTPS Microsoft host, valid Microsoft signature, one Professional image, SHA-256 recorded.
9. Require the unattended guest agent to become ready on an interactive session and the clean checkpoint to exist.
10. Require the configured one-to-four pool definitions, immutable base, differencing children, disconnected worker network, SYSTEM broker task, and location pointer.
11. Require installed runtime skill and managed policy block without replacing unrelated Codex instructions.
12. Run the visual canary through the broker, never on the host.
13. Require payload child deletion, pool audit success, terminal setup success, and current local recovery manifest unless explicitly skipped.
14. Remind the user that Windows activation and licensing were not performed.
